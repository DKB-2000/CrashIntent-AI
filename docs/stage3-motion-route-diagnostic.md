# Stage3 움직임 의존성·경로별 실패 진단 (2026-09-10)

## 범위와 방법

기존 1000클립 확대 모델을 고정해 로컬 CPU FP32로 진단한다. 학습, 라벨 수정, 제출 ZIP 교체, 외부 업로드는 수행하지 않는다. 경로 분석은 이전 200클립 모델과 확대 모델의 같은 외부 검증 31영상 18,603시점을 비교한다. 조향은 원본 정답 STOPPED 1,257시점을 제외한 17,346시점이다. 반복 사용한 개발 검증이며 공식 정답·비공개 평가 데이터는 아니다.

움직임 검사는 검증 4경로 × 조향 3범주 × 과거 16프레임 라벨 안정/비안정 × 2개 = 48클립을 고정 선택했다. 모델 정오답을 선택 기준으로 사용하지 않았다. 같은 층에서는 서로 다른 영상을 우선하고, 동일 영상의 선택 구간은 겹치지 않도록 했다. 모든 표본은 주행 중이며 시작 15프레임 패딩 구간은 제외했다.

각 16프레임 입력에 다음 네 조건을 적용한다. 현재 시점인 마지막 프레임은 모두 같다.

- 정상: 시간 순서 유지.
- 과거 순서 섞기: 앞 15프레임만 고정 seed로 섞는다.
- 과거 역순: 앞 15프레임을 역순으로 놓고 마지막 프레임을 유지한다. 전체 영상 역재생과 다르다.
- 마지막 프레임 반복: 같은 현재 이미지를 16번 입력해 프레임 간 움직임을 제거한다.

변형 영상은 실제 주행의 새로운 정답을 뜻하지 않는다. 원래 라벨 대비 정확도는 민감도 진단용으로만 비교한다. 순서 파괴는 학습 분포 밖 입력을 만들 수 있다. 예측 변화는 시간 정보 의존성의 증거지만 물리적으로 올바른 움직임 추론을 보장하지 않는다. 반대로 예측이 유지돼도 시간 정보를 전혀 쓰지 않는다고 단정할 수 없다.

## 경로별 실패

확대 모델의 원본 센서 대리 라벨 기준 조향 재현율이다.

| 경로 날짜 | 좌회전 | 직진 | 우회전 | 주행 중 시점 |
|---|---:|---:|---:|---:|
| 07-29 | 82.31% | 22.09% | 15.42% | 1,719 |
| 08-02 | 81.95% | 1.75% | 43.25% | 6,083 |
| 08-14 | 15.87% | 80.63% | 16.77% | 7,744 |
| 08-16 | 0.00% | 90.03% | 9.06% | 1,800 |

8월 2일의 직진 실패는 한 영상에 국한되지 않는다. 이 경로 11영상 모두 직진 재현율이 10.35% 이하이고 5영상은 0%다. 전체 직진 오류 4,231시점 중 2,971시점(70.22%)이 이 경로에서 발생한다. 반면 8월 16일은 좌회전 정답 353시점을 전부 놓쳤고, 전체 1,800시점 중 1,613시점을 직진으로 예측한다.

단순한 라벨 경계·전환 지연 가설로는 부족하다. 8월 2일에서:

- 과거 16프레임 라벨이 모두 직진인 안정 구간: 1,915시점, 직진 재현율 1.67%.
- 보정 조향각 절대값 1도 이내: 직진 2,488시점, 재현율 1.53%. 현재 직진 경계 ±1.5도에서 떨어진 구간도 실패한다.
- pose 회전속도 절대값 0.003rad/s 이내: 직진 2,093시점, 재현율 1.48%.
- 속도 25m/s 초과: 직진 2,321시점, 재현율 1.25%. 같은 속도 범위의 8월 14일 직진은 91.64%, 8월 16일은 89.98%다.

이 비교는 속도 하나의 구간을 맞춘 관찰이며 카메라·조도·도로 형태까지 통제한 인과 실험은 아니다. 특정 배경이나 조도에 의존한다고 확정하지 않는다. pose도 공식 정답이 아니고 기존 보정에서 참고한 신호다.

## 움직임 검사 결과

21영상에서 선택한 48클립 × 4조건 = 192회 CPU FP32 추론을 완료했다. 정상 입력의 가감속·조향 분류는 모두 기존 GPU 저장 예측과 48/48 일치했다. 아래 정확도는 클래스·경로·안정도를 고르게 뽑은 진단 표본의 값이며 전체 검증 F1이나 공식 점수가 아니다.

| 조건 | 조향 분류 변화 | 조향 정확도 | 평균 조향 확률분포 변화(TV) | 가감속 분류 변화 | 가감속 정확도 |
|---|---:|---:|---:|---:|---:|
| 정상 | 기준 | 17/48 (35.42%) | 0 | 기준 | 23/48 (47.92%) |
| 과거 순서 섞기 | 4/48 (8.33%) | 17/48 (35.42%) | 0.0330 | 6/48 (12.50%) | 26/48 (54.17%) |
| 과거 역순 | 4/48 (8.33%) | 18/48 (37.50%) | 0.0374 | 6/48 (12.50%) | 26/48 (54.17%) |
| 마지막 프레임 반복 | 7/48 (14.58%) | 15/48 (31.25%) | 0.0752 | 12/48 (25.00%) | 31/48 (64.58%) |

TV는 정상 대비 softmax 확률 차이 절대값 합의 절반(범위 0–1)이다. argmax가 같아도 확률은 달라질 수 있어 함께 기록했다.

조향은 움직임을 제거해도 41/48 분류가 유지됐다. 프레임 반복으로 원래 정답 17개 중 3개를 잃고 원래 오답 31개 중 1개만 수정했다. 30개는 계속 오답이다. 안정 조향 24클립에서는 순서 섞기 후 분류 변화 0개, 마지막 프레임 반복 후 변화 2개였다.

경로별 마지막 프레임 반복 후 조향 변화는 07-29 2/12, 08-02 2/12, 08-14 3/12, 08-16 0/12다. 08-16은 순서 섞기·과거 역순에서도 0/12이며 평균 확률분포 변화도 반복 조건에서 0.0219로 작았다. 반복 입력의 예측 분포는 07-29 LEFT 12/12, 08-02 LEFT 8/RIGHT 4, 08-14 STRAIGHT 8/RIGHT 3/LEFT 1, 08-16 STRAIGHT 11/LEFT 1이다. 단일 현재 이미지 입력에서도 경로별 편향이 상당 부분 남는다.

가감속은 조향보다 변형에 더 민감했다. 이 작은 표본에서는 오히려 프레임 반복 정확도가 높았으므로, 정상 시간 순서가 일관되게 도움을 준다는 증거는 확보하지 못했다. 이를 근거로 제출 추론을 반복 프레임으로 바꾸면 안 된다. 표본은 조향 진단을 위해 뽑았고 정지 클래스는 없으며, 가감속 클래스 균형이나 별도 검증셋을 갖춘 비교가 아니다.

## 해석과 다음 개선 순서

이번 결과는 시간 정보를 전혀 사용하지 않는다는 판정이 아니다. 조향 분류는 일부 바뀌고, 프레임 반복으로 정확도가 소폭 하락했다. 다만 다수의 오답과 경로별 편향이 시간 정보를 제거한 입력에도 남아 있어, 현재 영상 모델이 시간 단서를 충분히 활용하는지와 화면의 정적인 단서에 얼마나 의존하는지를 구분할 추가 실험 근거가 생겼다. 도로 모양만으로 조향을 알 수 있는 구간도 있으므로 낮은 시간 민감도가 곧 오류는 아니다. 카메라·조도·도로 배경 중 어떤 요인이 원인인지는 아직 분리하지 못했다.

1. 다음 비교 모델은 동일 출처 분할에서 단일 프레임 기반 대조군과 움직임 특징 기반 대조군을 두어, 정상 시간 정보의 추가 이득을 검증한다. 같은 MViT에 비정상 입력을 넣는 현재 검사와 구분되는 학습 대조 실험이다.
2. 경로×조향 클래스별 학습 표본 수와 성능을 함께 확인한다. 전역 클래스 균형만으로 이번 경로 편향이 해결됐다고 볼 수 없다. 개발 지표는 08-02 직진, 08-14/08-16 좌·우회전 재현율을 함께 추적한다.
3. 사람 검증셋은 이러한 비교를 평가할 독립 기준으로 추가한다. 현재 4경로는 반복 사용한 개발용이며, 이 결과만으로 모델을 승격하지 않는다.

추가 에폭·라벨 임계값 변경·좌우 교환을 이번 작업에서 실행하지 않았다. 이번 진단으로 공식 점수 하락의 단일 원인이 확정된 것도 아니다.

## 독립 검증

독립 검증 PASS. 21개 원본 영상을 다시 디코딩해 192개 입력 텐서 해시를 전부 재현했다. 원본 라벨·센서·분할·결과 ZIP·모델·코드 해시를 확인하고, 움직임 지표 80행과 경로별 지표 108행 및 클래스 지원 수·재현율을 별도 계산으로 대조했다. 움직임 지표 최대 계산 차이는 9.89e-17이다. 정상 CPU 분류와 기존 GPU 분류는 가감속·조향 모두 100% 일치했다. 검증 결과는 `artifacts/stage3-motion-route-20260910/validation.json`에 있다.

## 실행 및 산출물

```powershell
.\.venv\Scripts\python.exe src/diagnose_stage3_motion.py prepare
.\.venv\Scripts\python.exe src/diagnose_stage3_motion.py run
.\.venv\Scripts\python.exe src/diagnose_stage3_motion.py summarize
.\.venv\Scripts\python.exe src/validate_stage3_motion.py
```

`run`은 각 추론 완료 시 자동 저장한다. 중단 시 같은 명령으로 재개하며 입력·모델·코드 해시가 달라지면 중단한다. 새 실험은 별도 출력 폴더를 사용한다.

자료: `artifacts/stage3-motion-route-20260910/`의 `samples.csv`, `provenance.json`, `probe-logits.json`, `motion-summary.csv`, `route-strata.csv`, `route-strata-classes.csv`, `video-classes.csv`, `highspeed-class-recall.csv`, `route-concentration.json`. 최종 검증은 `validation.json`을 확인한다.
