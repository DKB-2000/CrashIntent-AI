# Civic 속도 반영 조향 기준 교차검증 (2026-09-14)

검증 실행 완료, 결과 `FAILED_NO_EVALUATION_LABELS`. 세 분할 모두 적합용2경로에서
기준을 통과하는 임계값이 없어 제외경로에 적용할 기준을 선택하지 못했다.
이는 영상 모델 성능 평가가 아니라 센서 대리 라벨 생성법의 개발 검증이다.

보정3경로를 한 번씩 제외하고 나머지2경로의1초 간격 표본만으로
조향각 = 영점 + (1000×b1/속도 + b2×속도)×yaw 관계식을 적합했다.
조향각과 속도로 추정한 yaw에 ±0.003/0.006/0.009/0.012rad/s 후보를 적용했다.
적합경로에서 직진≥90%·뚜렷한 회전≥97%,각30표본 이상을 만족하는 최소 임계값을
선택하고 제외경로에서도 같은 기준을 통과해야 한다는 계획을 실행 전에 고정했다.

| 제외 경로 | 적합2경로에서 ±0.006 직진/회전 | ±0.009 직진/회전 | 선택 |
|---|---:|---:|---|
| 05-05 | 83.33% / 97.12% | 95.04% / 94.57% | 없음 |
| 05-12 | 68.39% / 99.31% | 85.69% / 95.98% | 없음 |
| 05-13 | 77.01% / 99.31% | 87.76% / 94.86% | 없음 |

±0.003과±0.012도 동시 기준에 미달했다. 후보를 선택하지 못했으므로
제외경로 예측은 모두UNKNOWN이다. report.json의 held_metrics/pooled_diagnostic에
기록된 일치율0은 UNKNOWN을 정답과 대조한 내부 집계값이며 실제 채택된 기준의
성능0%를 의미하지 않는다. 새 평가2경로의 라벨·예측은 생성하지 않았다.

보정3602시점 중 유효 센서 경계·속도5~35m/s·|pose yaw|<0.12 조건에2695행이
해당하고907행이 제외됐다. 일치율 대상은 직진671/회전1260행이며 중간764행은
분모에서 제외했다. 경계 제외·속도 범위 제한을 숨긴 전체 분포 성능으로 해석하지 않는다.
