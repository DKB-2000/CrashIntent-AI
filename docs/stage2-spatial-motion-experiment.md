## 가설과 고정 조건

이전 전후 평균은 같은 BiGRU hidden의 시간 요약만 변경했다. 이번에는 원본 전체 화면을
160×96으로 축소하고 4×4영역별 밝기 평균·표준편차 및 인접 프레임 optical flow의
평균 x/y·크기를 추가한다. 좌우 위치·움직임과 주변 장면의 가시성이 분류에 도움이 되는지
검사하는 저비용 대조다. 차량 탐지·차선·빈 공간을 직접 추정하는 특징은 아니며,
밝기·움직임이 실제 회피 가능 공간을 나타낸다고 가정하지 않는다. 160×96 축소는 종횡비를
약간 변경하며 첫 프레임 flow는0으로 처리한다.

기존 source-CV fold별 soft_mixed_15 temporal 모델과 두 argmax시점 고정.
새 특징도 정답시점이 아닌 예측 충돌·진입시점에서 각각80차원씩 추출한다.
기존768차원+새160차원, 동일928→192→4 head에서 추가160열은0 초기화한다.
point(추가열 입력0), motion(96차원), spatial(64차원), combined(160차원) 네 조건이다.
같은 초기 기존 head, batch순서·dropout seed·AdamW lr2e-4·15epochs·batch8·clip1 적용.
5fold×3seed(20260825/26/27)×4조건=60개 scene head. 새로운 backbone은 없다.
추가 특징 정규화는 각 fold의 학습영상 예측시점 벡터만 사용하며 검증 통계는 사용하지 않는다.

## 판단 기준

회피/방향 정확도, 고정된 충돌/진입 ±0.3초 정확도, 네 항목 평균과 출처동일가중 평균을
조건별·seed별로 기록한다. 같은 출처분할을 여러 번 사용한 개발 실험으로, 최고값을
독립 검증 성능으로 보고하지 않는다. 외부fold 성능으로 에폭·특징크기·seed를 선택하지 않는다.
후속 후보를 정해도 Nexar 사람 검수와 최종 라벨 대조 전에는 제출 모델을 교체하지 않는다.
