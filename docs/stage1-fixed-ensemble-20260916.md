# Stage1 고정 확률 결합 대조 (2026-09-16)

사람 라벨 없이 생성 절차가 정답을 확정한 기존 개발 영상 420개에서, 저장된 CUDA FP16 예측을 사용해 최고 baseline과 보강 모델을 각각 50:50 확률 평균으로 결합했다. 판정 임계값은 기존 0.5로 고정했다. 세 예측 파일은 각 420행이며 입력 경로·출처·그룹·영상 해시·조건·정답·행 순서가 일치함을 확인했다. 원격 실행이나 모델 재학습은 하지 않았다. 재현 코드: `src/compare_stage1_fixed_ensemble.py`.

| 조건 | 원본 노이즈 오류 /21 | 원본 복합화질 오류 /21 | 화면단서 약화 재녹화 오류 /21 | normal63 Macro-F1 |
|---|---:|---:|---:|---:|
| 최고 baseline | 19 | 18 | 0 | 1.0 |
| mixed_50 단독 | 0 | 9 | 3 | 1.0 |
| screen_mix_50 단독 | 4 | 12 | 2 | 1.0 |
| baseline + mixed_50 확률 평균 | 12 | 17 | 0 | 1.0 |
| baseline + screen_mix_50 확률 평균 | 15 | 17 | 0 | 1.0 |

두 고정 결합 모두 기존 사전 gate(노이즈·복합화질 각각 개선, 모든 재녹화 조건 오류 증가≤1/21, normal F1 감소≤0.02)는 통과한다. 다만 원본 복합화질 개선이 18→17로 미미하며, 반복 사용한 단일 개발 출처의 합성 자료다. 9월15일 화면단서 모델 단독의 공식 Stage1 점수는 기존 최고보다 낮았다. 따라서 결합 결과를 일반화 개선이나 제출 후보로 채택하지 않는다. 별도 출처·실제 재촬영 자료가 없으므로 정확도 확인은 제한된다. 모델·ZIP·selected·예약은 변경하지 않았다.

로컬 Python `.venv`가 없는 Python311 설치를 가리켜 스크립트 실행은 실패했다. 동일 계산은 예측 JSONL 3개를 직접 읽어 420행 대응·고정 평균·조건별 오류·normal Macro-F1을 검산했다. Python 환경 복구 후 스크립트 재실행 가능하다. 다음 학습 실험은 기존 합성 재녹화 노출을 유지하고, 학습 출처에만 약한 화면단서를 추가하는 배치 비율 대조가 필요하다.
