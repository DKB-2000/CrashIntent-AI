# Stage3 전환 직진 보강 후보 점검

2026-09-14 완료. 기존 1,000개 학습 표본은 같은 CSV 해시로 보존했다. 모델 학습은 실행하지 않았다.

학습 17개 경로의 고정 센서 라벨만 사용했다. 주행 중 직진↔회전 라벨 전환 2,853개 중 전후 각 10시점의 주행 상태와 라벨이 유지되는 전환은 791개였다. 해당 전환의 직진 쪽 1초 이내에서 입력 길이 16프레임을 확보할 수 있는 고유 시점은 7,341개다. 기존 입력과 한 프레임도 겹치지 않는 것은 5,246개다.

전환당 최대 한 시점, 추가 후보끼리도 입력 프레임 비중복 조건을 적용해 574개 후보를 고정했다. 난수 시드는 20260918이다. 17개 학습 경로를 모두 포함한다.

791개 지속 전환 중 기존 학습 직진 endpoint가 해당 직진 쪽 1초 안에 있는 전환은 65개였다. 이는 endpoint 커버리지이며, 나머지 전환을 기존 입력 영상이 전혀 포함하지 않는다는 뜻은 아니다. 현재 후보 수나 낮은 endpoint 커버리지만으로 학습 부족 또는 보강 이득을 확정할 수 없다.

574개는 후보 저장 목록이며 최종 균형 학습 목록이 아니다. 이를 그대로 추가하면 직진·가감속·경로별 학습 비중이 달라진다. 다음 대조 설계에서는 기존 표본 전부와 기존 정규화 값을 보존하고, 동일한 추가 업데이트 및 클래스 노출 횟수를 사용하는 대조군을 구성해야 한다. 경로×가감속×속도 구간을 맞출 수 있는 후보 수부터 확인한다. 원래 검증 경로의 오답은 학습으로 이동하지 않는다.

센서 라벨의 지속을 사용했으며 사람의 실제 회전 판정은 아니다. 입력 프레임이 겹치지 않아도 같은 영상·경로의 시간적 상관은 남는다. 영상 경계를 넘는 중복 또는 GPS 기준 중복 제거를 의미하지 않는다.
