## 우회전 손실 1.25배 대조 완료 (2026-09-16)

사용자가 확인한 Python 3.11 경로로 `.venv` 실행을 복구해 `src/train_stage3_right_weighted_control.py watch`를 시작했다. 일반 CE와 동일한 1,180표본·1,560업데이트·3시드·정규화·초기 체크포인트·배치 일정에서 주행 중 RIGHT 정답의 조향 CE 손실에만 1.25배 가중치를 적용했다. 기존 일반 CE 결과는 재학습하지 않고 체크포인트와 검증 로짓을 재생했다. 가중치는 검증 정답으로 고르지 않았다.

감시 `COMPLETE`, 결과 `COMPLETE_VALIDATED`, 최종 `KEEP_BASELINE`. 평균 개발 조향 F1은 기존 **0.684695**, 일반 CE **0.720351**, 우회전 가중 **0.718007**이다. 가중 조건은 일반 CE보다 우회전 재현율을 0.7243%p 회복했지만 기존보다 여전히 **4.3890%p 하락**했고, 직진 재현율은 기존보다 10.1764%p 상승했다. 전환 미검출·지연 기준도 실패했다. 일반 CE와 비교한 F1은 3시드 모두 0.21~0.25%p 하락했다.

고정 입력·특징·초기 로짓, 9체크포인트·검증 로짓, 신규 3 CSV·혼동행렬·전환 지표 검증을 통과했다. 후속 독립 SHA256 확인에서도 기록된 모델·로짓 파일 불일치 0건, 전환 CSV 해시 일치를 확인했다. 결과는 `artifacts/stage3-right-weighted-control-20260916/final-review.json`, 감시 기록은 같은 폴더의 `train-watch-status.json`이다. 기존 공식 모델과 제출 ZIP을 유지한다. 새 블라인드 검수셋은 사람 라벨 0개이므로 이번 조건의 독립 사람 점수는 없다.
