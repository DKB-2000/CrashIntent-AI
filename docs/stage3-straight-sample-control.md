반복된 특징 변경의 성능 하락 이후, 실제 학습 표본 감사 결과를 바탕으로 학습 구성만 바꾸는 대조 실험을 준비했다.

기존 1,000개 중 직진 84개를 교체했다. 주행 중 직진·좌·우 각각 300개와 정지 100개를 유지하며, 각 슬롯의 경로·가감속·조향·속도 구간도 같다. 기존의 안정적인 직진과 모든 회전·정지 표본은 보존했다. 조건을 충족하는 직진은 143개에서 227개가 됐다.

교체 후보는 학습 경로에서만 선택했다. 기존 직진 라벨, 속도 5m/s 이상, pose yaw 절댓값 0.003rad/s 미만, 전후 5개를 포함한 11시점의 직진 라벨 유지, 조향 임계값에서 0.25도 초과 거리, endpoint 15 이상을 요구했다. 경로×가감속×속도 구간별 절반까지만 교체했다. 이 기준은 센서 기반 선별이며 사람의 정답 확인을 대신하지 않는다. 미래 시점은 오프라인 표본 선정에만 사용한다.

원본과 교체 표본 각각 3개 시드, 동일 MLP·특징·정규화 방식·1,200회 업데이트를 사용한다. 기존 표본을 다시 학습한 3개 결과의 검증 logits가 저장된 원본과 정확히 일치해야 교체 표본 학습으로 진행한다. 추가 특징 추출에서는 영상 원본 해시와 기존 endpoint의 특징 일치도 검사한다.

평가는 기존 개발 4개 경로 전체에서 한다. 사전 조건은 세 시드 모두 F1 증가, 평균적으로 4개 중 3개 이상 경로 개선, 클래스 재현율 손실 2%p 이내이다. 전환 실패·지연도 추가 검토해야 하므로 학습 완료만으로 채택하지 않는다. 새로운 Civic 평가 결과로 표본을 조정하지 않는다.

속도 구간은 같지만 실제 속도와 영상의 동일성을 보장하지 않으며, 안정적인 표본 선별은 전환 다양성을 줄일 수 있다. 성능 개선은 아직 확인되지 않았다.
