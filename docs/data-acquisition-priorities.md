# 모델 고도화를 위한 데이터 확보 우선순위

기준일: 2026-09-09. 프로젝트 최신 인수인계와 개발 평가 기록을 기준으로 정리했다.
아래 수량은 단계별 확보 목표이며 성능을 보장하는 최소량은 아니다.

현재 우선순위는 **Stage2 정답 라벨 확보 → Stage1 실제 재촬영 데이터 → Stage3 부족한 주행 장면 보강**이다.
외부 데이터도 필요하지만, 당장 가장 큰 병목은 이미 확보한 영상을 정확한 정답이 있는 학습·검증 데이터로 만드는 일이다.

## 확보 순서

| 우선순위 | 필요한 데이터 | 현재 상태와 부족한 점 | 우선 확보 목표 | 확보 방법 |
|---|---|---|---|---|
| 1 | Stage2: 진입·충돌·방향·회피 공간을 판정할 수 있는 사고 영상과 4항목 정답 | CCD 영상 1,500개 확보. 수동 라벨 74건 중 최근 평가에 사용 가능한 것은 66건 | 유효 라벨 200~300건, 현재보다 134~234건 추가 | 기존 CCD에서 적합 영상 선별·수동 라벨링. 추가 다운로드 없이 가능 |
| 2 | Stage1: 실제 원본–재촬영 쌍 | 합성본만으로는 실제 휴대전화 재촬영 판별 성능을 확인하기 어려움 | 학습에서 제외한 원본 30개 + 실제 재촬영 90개 | 모니터 재생 영상을 휴대전화로 각 3조건 촬영. 검증용으로 보존 |

| 6 | Stage3: 다른 차량의 주행 영상·센서 | 현재 첫 청크는 RAV4 중심 | Civic 청크를 추가해 총 약 400분 구성 검토 | comma2k19 추가 다운로드. 기존 데이터에서 정상 학습을 확인한 뒤 확대 |

## Stage2 라벨 확보 시 주의할 점

- 좌·우 진입과 회피 공간 있음·없음이 골고루 포함되도록 선별한다.
- CCD의 사고 구간 시작 라벨이 실제 접촉 프레임과 맞는지도 확인한다.
- 진입 시점·방향·회피 공간이 불명확한 영상은 억지로 정답을 만들지 않고 보류한다.
- 기존 200개 영상 검수에서 유효 66건을 확보했다. 같은 비율이라면 목표까지 약 400~710개 영상을 추가 검수해야 한다. 이는 단순 작업량 추정이며 선별 방식에 따라 달라진다.
- 동일 원본 출처의 영상이 학습·검증에 함께 들어가지 않도록 분리한다.

최근 평가 근거: [Stage2 수동 라벨 74건 개발 평가](stage2-manual-test-200.md).

## 외부 다운로드 우선순위

외부 다운로드만 비교하면 **ZOD → Nexar → comma2k19 다른 차량 청크** 순서를 권한다.
ZOD 접근이 열리지 않으면 Nexar 소량 선별을 먼저 진행할 수 있다.

- **ZOD**: 연속 영상과 차량 데이터를 제공하므로 Stage3 보강 후보이다. 실제 확보 후 timestamp·신호 부호·단위와 필요한 주행 장면의 포함 여부를 확인한다. [공식 안내](https://zod.zenseact.com/), [Sequences](https://zod.zenseact.com/sequences/).
- **Nexar**: 학습 데이터의 positive 750개에는 실제 충돌 400개와 근접사고 350개가 포함된다. Stage2에는 실제 충돌과 진입 장면을 확인할 수 있는 영상만 선별한다. `alert time`은 사고를 예견할 수 있는 시점이므로 대회의 진입 시점 정답으로 사용하지 않는다. [공식 데이터 설명](https://www.kaggle.com/competitions/nexar-collision-prediction).
- **comma2k19 추가 청크**: 차량 다양성 보강용이다. 현재 데이터에서 학습이 정상 동작하는지 확인한 후 확대한다. [공식 배포 계정](https://huggingface.co/datasets/commaai/comma2k19).

출처·라이선스·기존 사용 결정은 [DATA_SOURCES.md](../DATA_SOURCES.md)를 따른다.

## 모델 고도화와 병행할 작업

Stage3의 한 클래스 쏠림은 데이터 부족으로 확정되지 않았다. 확보한 작은 고정 표본 10개도 충분히 학습하지 못한 상태이므로,
FP32 대조와 규제 비활성 대조, scaler skip 등 학습 안정성 진단을 먼저 끝내야 한다.
센서에서 만든 범주 라벨 역시 공식 정답과 일치한다고 확정된 것이 아니므로 표본 검수를 유지한다.

모델 진단을 진행하는 동안 사람이 필요한 **Stage2 라벨링과 Stage1 실제 재촬영**을 진행하는 것이 우선이다.
Stage1 합성 데이터 생성은 기존 원본으로 자동화할 수 있다.
