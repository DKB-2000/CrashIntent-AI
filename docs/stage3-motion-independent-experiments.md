# Stage3 움직임 개선 독립 실험 (2026-09-10)

사용자가 승인한 1번 공간 움직임 분리와 2번 시간 길이·이미지 결합을 서로 분리해 비교한다. 공식 Stage3 0.4187467089를 기록한 제출 후보 ZIP을 보존한다.

## 공통 조건

기존 학습 1,000표본과 경로가 겹치지 않는 개발 검증 31영상 18,603시점, 초기값 20260910/11/12, 동일 1,682입력 MLP와 고정 12에폭·1,200업데이트를 사용한다. 입력 차원은 유지하되 사용되는 특징을 바꾸므로 활성 연결 수는 다를 수 있다. 학습 표본에서만 평균·표준편차를 계산하고 검증으로 에폭·seed를 고르지 않는다. 학습은 원본과 같은 CPU 2스레드를 맞춘다.

두 실험의 모델 저장·예측 재현 검증에 더해 `src/evaluate_stage3_motion_slices.py`가 독립적으로 모든 예측의 ID/시점, 가감속·조향 혼동행렬, 클래스별 정밀도·재현율·F1을 재계산한다. 평가 조건은 `artifacts/stage3-motion-independent-20260910/plan.json`에 결과 확인 전에 고정했다.

- 정지 1,257시점, 주행 중 2m/s 미만 305시점, 2~5m/s 428시점, 5m/s 이상 16,613시점.
- 저속 주행 733시점은 3경로/8영상에서 나온다. 서로 독립된 733영상으로 해석하지 않는다.
- 전환 전후 5프레임과 그 밖의 안정 구간, 4개 경로를 따로 비교한다.
- 속도 센서와 미래 정답은 사후 평가 구간 구분에만 사용하며 모델 입력·추론에는 사용하지 않는다.
- 조향은 정답 STOPPED를 제외한다. 구간별 Macro-F1은 4개 가감속/3개 조향 클래스를 고정하므로 지원 표본 없는 클래스가 있는 구간에서는 전체 점수와 직접 비교하지 않는다.

## 2번: 시간 길이·이미지 결합

기준선은 현재/최근5/최근15개 흐름, 짧은 창은 현재/3/5, 긴 창은 현재/15/30, 결합은 긴 창+현재 이미지다. 인접 프레임 사이 흐름이므로 최근30개 흐름은 최대31프레임을 필요로 한다. 약10Hz 영상에서 최대3초의 과거를 사용하는 인과적 요약이다.

검증영상은 기존 매 프레임 흐름 캐시를 재사용하며 학습영상만 필요한 과거 프레임을 추가 추출한다. 실행 최적화와 CPU 스레드 정정은 별도 해시·기록을 남기고 사전 모델 조건과 결과물 경로를 보존했다. 12개 조건 결과를 확보했다(10개 신규 학습과 2개 원본 기준선 재사용). 두 실험 합계는 19개 신규 학습과 2개 재사용이며, 별도 스레드 수치 재현 진단은 이 개수에서 제외한다.

## 해석 범위

모든 수치는 반복 사용한 외부 개발 경로의 센서 대리 라벨 평가다. 공식 점수 0.4187467089와 외부 조향 F1 0.684695는 서로 다른 평가이므로 직접 상승폭을 환산하지 않는다. 공식 평가파일·정답은 사용하지 않았다. 이번 작업은 신규 GPU 업로드, 제출 ZIP 교체 또는 대회 제출을 포함하지 않는다.

**판단: 현재 공식 .4187467089 제출 모델을 유지한다. 공간 분리·영역 요약·긴 창·긴 창+이미지는 이번 조건에서 채택하지 않는다. 짧은 창만 별도 출처·사람 검증용 후속 후보로 보존한다.** 개발 경로만으로 즉시 새 제출 모델을 선택할 근거는 부족하다. 기준을 보존하고 저속직진 개선과 우회전 손실이 다른 영상에서도 나타나는지 확인하는 것이 다음 단계다.
