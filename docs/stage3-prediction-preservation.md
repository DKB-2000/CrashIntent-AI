# Stage3 기존 예측 보존 추가 학습

2026-09-14 사용자 후속 개선 요청으로 준비하고 실행한다. 우회전 표본 추가 후 평균 F1은 올랐지만 우회전 재현율이 더 떨어져, 같은 표본을 사용하는 학습 방식 대조로 전환했다.

두 조건 모두 각 시드의 기존 모델에서 시작한다. 입력은 원본 1,000개와 직진 90개·우회전 90개, 이전 실험과 같은 1,560회 업데이트 일정이다. 기존 정규화 값을 고정하고 새 AdamW 옵티마이저를 사용한다. 학습률은 0.0001, weight decay 0, gradient clip 1이다. 마지막 체크포인트만 평가한다.

| 조건 | 손실 |
|---|---|
| warmstart_ce | 기존 가감속·주행 조향 정답 교차엔트로피 |
| warmstart_preserve | 위 손실 + 기존 표본의 주행 조향 예측 보존 항 |

보존 항은 같은 시드의 동결된 기존 모델을 교사로 사용하는 KL(교사 확률 || 학생 확률)이다. 온도 2, 가중치 1, 온도 제곱 보정을 사전에 고정했다. 배치에서 원본 1,000개에 속하는 주행 표본만 적용하며 방향별 가중치를 다르게 주지 않는다. 새 180개에는 정답 손실만 적용한다. 검증 자료로 교사 목표를 만들거나 설정을 탐색하지 않는다.

보존 항이 없는 대조군도 동일한 체크포인트·표본·배치·업데이트·학습률을 사용한다. 따라서 두 조건 비교로 이 제약의 효과를 평가한다. 이전 재학습과 비교할 때는 초기화와 학습률 등도 달라졌다는 점을 구분한다. 교사 모델의 오류도 보존할 수 있으므로 이 방법이 개선을 보장하지 않는다.

각 조건을 기존 모델과 비교해 세 시드 모두 F1 증가, 네 경로 중 세 경로 이상 평균 증가, 클래스 재현율 손실 2%p 이내, 시드별 회전 시작·종료 미검출 증가 없음과 조건부 평균 지연 증가 0.1초 이내를 요구한다. 보존 제약군과 일반 추가 학습 간 차이도 별도 보고한다. 기존 개발 센서 라벨 평가이며 자동 배포는 하지 않는다.

예측 동일 시 KL 약 0, 예측 변경 시 양의 손실 및 유한한 역전파, 교사 가중치 gradient 없음 검사를 통과했다. 기존 특징·표본·배치 해시 검증, 6개 초기 모델의 저장 로짓 정확 재현, 학습 후 저장 모델 재추론·CSV 검산·전환 지표 검증을 실행 코드에 연결했다.

실행은 `src/train_stage3_prediction_preservation.py watch`. 저장 특징을 재사용하며 영상 변환은 없다. 1시간 제한, 재시도 0, 중복 잠금, 실패 상태·로그를 사용한다. 결과는 `artifacts/stage3-prediction-preservation-20260914`의 `status.json`, `train-watch-status.json`, `train.log`, `final-review.json`에 남긴다. `COMPLETE_VALIDATED` 및 감시 `COMPLETE` 이전에는 완료가 아니다. 상태는 `./scripts/Get-BackgroundWorkStatus.ps1`로 한 번 조회한다.
