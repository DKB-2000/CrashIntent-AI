## 입력과 비교 규칙

- 기존 최종 검증 준비에서 동결한 `incumbent`, `ccd_pretrained`와 공통 ResNet18을 CPU FP32로 실행한다.
- Nexar 후보 50개 전체, 57,483개 원래 프레임을 사용한다. AI 검토 결과로 대상을 골라내거나 공식 참고 이벤트 시각을 정답으로 쓰지 않는다.
- 각 JPEG 해시 확인 후 특징을 한 번 추출해 두 모델에 공유한다. 저장 특징은 모델 출력 재현 검증에 사용한다.
- 원본 PTS/timebase의 유리수 시각으로 충돌·진입 예측의 시간차를 계산한다. 0.3초 초과는 **모델 간 차이** 기준이다. 채점 성공 기준으로 해석하지 않는다.
- 회피 공간·진입 방향의 불일치와 분포, 진입이 충돌보다 늦게 예측되는 건수를 기록한다. 이런 진단만으로 어느 예측이 맞는지 알 수 없다.
- 50개 모두 충돌 적합성·녹화 출처 독립성에 미확정 부분이 남아 있다.

## 최종 라벨 평가와의 관계

기존 `evaluation-contract.json`과 최종 평가 코드, `review-decisions.csv`는 수정하지 않는다. 기존 최종 채점 명령은 여전히 사람이 작성한 정답을 요구한다. 이번 작업은 그 경로와 별도다.
