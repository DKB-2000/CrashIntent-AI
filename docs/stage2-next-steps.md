## 다음 순서

1. **공식 최고 모델 유지 및 후보 보존**
   기존 Stage2 가중치는 artifacts/stage2-controls-20260909/soft_mixed_scene/best.pt.
   SHA256 ef5746c2f2c92bfce9bdc61ee59782bcde831692eb50cf74dfd303b328601500.
   BiGRU 고정 후보는 artifacts/stage2-regularization-20260911/의 외부fold별 모델로 보존한다.
   최고 fold를 임의로 선택해 제출하거나, 개발 최고값만으로 새 모델을 승격하지 않는다.

2. **검증 전용 라벨30~50건 확보**
   구·신 모델의 모든 학습에서 제외된 출처를 고른다. 새 사전학습1296영상의 출처도 검사한다.
   알려진 사전학습110출처와 수동학습23출처를 합친133출처를 제외해야 하므로,
   기존 CCD에서 출처가 남는다고 가정하지 않는다. 부족하면 별도 출처의 자료가 필요하다.
   자료 확보 시 출처·라이선스·중복 여부를 먼저 기록한다.
   선정된 검증 자료는 학습에 넣지 않고 구·신 모델에 동일한 이미지 입력으로 사용한다.
   충돌·진입 시점, 회피 공간, 방향의 판정 기준과 애매한 사례 처리 규칙을 정리한다.
   전체 평균뿐 아니라 출처별·항목별 성능과 예측 변화를 비교한다.
   이 자료로 설정을 반복 선택하면 개발셋이 되므로 변경 이력과 사용 목적을 남긴다.

3. **항목별 특징 분리 실험**
   방향에는 차량의 좌우 위치·이동, 회피 공간에는 주변 도로·빈 공간을 반영하는 특징을 대조한다.
   단순 전후 평균과 구분해 설계하고 먼저 작은 실험으로 실행 가능성과 효과를 확인한다.
   라벨 확보가 어렵다면 기존 출처 분할에서 탐색할 수 있지만 결과만으로 제출 모델을 교체하지 않는다.
   다음 번호 단계로 이동할 때는 사용자가 요청한 단계별 승인 조건을 따른다.

현재 승인된 것은 이 계획과 기록의 Git 정리·push다. 검증 자료 수집·추가 라벨링·
새 모델 학습·외부 전송·공식 제출은 이번 문서 정리에서 실행하지 않았다.
