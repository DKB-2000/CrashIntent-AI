# Stage3 클래스·경로별 오류 분석 (2026-09-10)

## 검증 및 범위

이전200클립 모델과 새1000클립 모델의 동일31영상18603시점 예측을 비교했다. 원본 결과ZIP SHA256, 검증 라벨CSV 해시, ID별1:1 결합, 기존 독립 F1과 재계산 일치 PASS. 조향은 정답STOPPED1257시점 제외(17346시점). 비공개 대회 데이터·점수는 사용하지 않았다.

## 전환 시점만의 문제인가

현재 포함 과거16시점의 정답이 같은 구간을 안정 구간으로 정의했다. 영상 시작15시점은 비안정 구간으로 분류했다. 미래 프레임은 사용하지 않는다.

- 가감속 정확도: 비안정40.88%, 안정63.95%.
- 조향 정확도: 비안정38.36%, 안정46.30%.

전환 부근이 어렵지만 안정 조향도 절반 이상 틀려 단순 지연이나 평활화만으로 설명되지 않는다. 구간별 클래스 분포가 달라 인과관계로 해석하면 안 된다.

이전 오답을 맞힌 시점/이전 정답을 잃은 시점: 가감속8396/2961, 조향6503/4375. 프레임은 상관되어 있으므로 이 수로 독립표본 유의성을 주장하지 않는다.

## 다음 실험 결정

우선 **같은1000클립·같은 배치·학습률에서 추가12에폭**을 시험해 학습량 부족 가능성을 확인한다. 학습 조향F1도0.5053에 머물고 마지막4에폭 손실2.0902→2.0591→2.0324→1.9442로 계속 감소해 추가 최적화의 근거가 있다. 개선 보장은 아니다.

이전 결과에는 optimizer state가 없으므로 가중치에서 시작하되 AdamW는 초기화한다. 정확한 중단 재개와 구분한다. 마지막 고정 체크포인트에서 같은31영상 전체를 평가하며 전체F1뿐 아니라08-02 직진 재현율·가속/우회전 재현율을 함께 비교한다. 이번 분석에서 학습을 새로 실행하지 않았다.

클래스 조합은 이미 각100클립으로 균형이므로 우회전 표본 가중치를 즉시 늘리는 근거는 부족하다. 새로운 표본 확대나 라벨 임계값 변경을 동시에 하면 원인 구분이 어려워 후순위로 둔다.

반복 확인한4검증경로는 이제 개발 검증으로 사용 중이다. 이 점수만으로 대회·새차량 일반화를 보장하지 않는다. 라벨은 센서 기반 대리값이며 영상 육안 검수 없이 잘못된 라벨이라고 단정하지 않는다.
