# Civic 센서 보정 점검 (2026-09-14)

점검 완료, 상태 `CALIBRATION_GATE_FAILED_NO_LABELS`. 고정 조향각 dead-zone 후보가
사전 기준을 통과하지 못해 평가용 조향 라벨은 생성하지 않았다. 모델 채점도 미실행이다.

## 분리와 검증

센서 수치를 분석하기 전에 seed20260915로 보정3경로/6구간, 평가2경로/4구간을 고정했다.
평가경로는05-01과06-11이며 보정에 사용하지 않았다. 획득110파일의 SHA256을 재검증하고
10Hz시점6002개를 구성했다. 각 구간 앞뒤1초와 CAN 범위 밖 시점을 제외해213행을
무효 처리했다. 영상원본 프레임 번호는 sample_index의2배로 별도 보존했다.

ECEF 위치·속도에서 수평 진행방향의 변화율을 구해 좌회전을 양수로 사용했다.
이 자세 기반 신호와 조향각의 관계로 영점을 추정했으며 자이로는 비교 진단에 사용했다.
보정 구간 중 속도5~35m/s, |yaw|<0.12rad/s, 1초 간격265행에서 robust 회귀:
조향각 = 영점 + 계수×yaw/speed + 계수×yaw×speed.
영점 후보는 +0.01135°, 절대잔차 중앙값0.50597°. 고정 보정의 물리적 정확성 인증은 아니다.
조향각의 양수가 좌회전에 대응하는 관계는 지지됐다.

## 임계값 검사

기존 프로젝트의 후보0.5/1/1.5/2° 중 보정용 자료에서 직진 일치≥90%,
뚜렷한 회전 일치≥97%를 동시에 만족하는 최소값을 선택하기로 사전 고정했다.
직진 비교는 |pose yaw|<0.003rad/s 671행, 회전은 >0.012rad/s 1260행이다.

| 조향각 범위 | 직진 일치 | 회전 일치 |
|---|---:|---:|
| ±0.5° | 48.44% | 99.76% |
| ±1.0° | 82.12% | 96.75% |
| ±1.5° | 93.14% | 90.63% |
| ±2.0° | 96.57% | 84.44% |

합격 후보0개. 이는 센서간 대리 기준 일치율이며 공식 조향 성능이 아니다.
평가셋 결과를 보고 임계값을 조정하지 않았다. 평가 CSV는 헤더만 있고 조향 라벨0행,
signals.csv의 steer_label은 전부UNKNOWN/valid_steer=false다. 속도 기반 가감속 열은
진단용 대리값이며 공식 라벨로 확정하지 않았다.

05-05 보정경로에서는 뚜렷한 회전809행의 자이로·자세 부호 일치가44.00%로 낮지만
조향각·자세 부호는100% 일치했다. 다른4경로는 해당 자이로 부호 일치100%였다.
자이로 바이어스·좌표축·정렬 가능성을 구분하는 추가 조사가 필요하며 원인은 아직 미확정이다.

다음은 보정3경로 안에서 **속도에 따른 조향각과 진행방향 변화의 관계 및 자이로 불일치**를
분석하는 작업이다. 이번 실패 기준을 완화해 평가 라벨을 억지로 만들지 않는다.
평가2경로의 신호 진단은 이미 열람했으므로 완전히 미열람인 테스트셋으로 과장하지 않는다.
