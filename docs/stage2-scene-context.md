## 실험

기존5분할/66영상/23출처의 soft_mixed15 모델을 사용한다. 각 분할의 시간 인코더·
충돌/진입 argmax를 고정하여 시점 성능 변화 없이 scene 특징만 대조한다.
원래 BiGRU 특징 자체도 전체 시퀀스 문맥을 포함한다. 따라서 새 영상 정보를 추가한 것이
아니라 시간별 hidden 표현을 요약하는 방식의 대조다.

- point: 기존 두 예측 시점 hidden을 연결한768차원 특징.
- window: 두 예측 시점 각각 전후 ±0.5초 hidden 평균을 연결한768차원 특징.
- 같은 기존 scene 가중치에서 시작하여 scene head만15에폭 미세조정.
- lr2e-4, AdamW 기본설정, batch8, gradient clip1, 기존 dropout.
- 3 seeds 20260825/26/27, 쌍별 동일 초기화·샘플순서·dropout seed.
- 학습·평가 모두 각 영상의 예측 시점 사용. 검증 라벨로 에폭이나 창 크기를 선택하지 않음.
- 모델3seed×2조건×5분할=30개. CPU45.48초 완료.
