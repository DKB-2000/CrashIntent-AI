## 1. 기존 1,000클립 표본 감사 완료

원격 확대 학습의 결과 ZIP 및 보고서에서 실제 사용한 표본을 읽었다. 로컬 학습/검증 라벨 해시는 원격 학습 보고서와 정확히 일치한다. 분할 manifest는 원격 패키징에서 영상 경로와 행 순서가 달라지므로 원본 GPU 학습 번들의 해시를 확인하고 ID별 route/split을 별도로 대조했다. 파일 해시 차이를 무시하고 진행한 것이 아니다.

- 학습 156영상, 17경로를 모두 사용했다. 검증 31영상/4경로와 경로 중복 없음.
- 가감속×조향 9개 주행 조합 및 정지 1개 조합: 각 100클립.
- 주행 중 좌/직진/우: 각각 300클립.
- 경로×조향 51개 조합: 모두 존재, 조합당 15~21클립.
- 경로×가감속×조향 153개 주행 조합: 모두 존재, 조합당 2~8클립.
- 정지 포함 경로당 총 표본: 50~62클립.
- 원본 영상 다양성은 다르다. 2018-07-29 16:37 경로는 50클립이 원본 2영상에서 나왔다. 경로×조향당 선택 영상 수는 2~13개다.

따라서 경로별 조향 범주가 빠져 생긴 실패라는 근거는 없다. 이미 경로·클래스 수를 상당 부분 균형화했다. 다만 각 세부 조합의 절대 표본은 작으며 조도·곡률·카메라·차선 형태까지 대표한다는 뜻은 아니다. 이번 실험에서는 표본을 바꾸지 않는다.

## 2. 비교 조건 (결과 확인 전 고정)

| 방식 | 입력 | 분류기 |
|---|---|---|
| image | 현재 한 프레임의 RGB 공간 격자 및 방향별 영상 경사 특징 | 동일한 작은 MLP |
| motion | 과거 16프레임에서 얻은 광학흐름 격자·크기 통계, 최근 1/5/15개 흐름의 요약 | 동일한 작은 MLP |
| combined | 위 두 특징을 함께 사용 | 동일한 작은 MLP |
| mvit_reference | 원래 16프레임 RGB 영상 | 기존 1000클립 확대 MViTv2-S 결과 재사용 |

공통 영상 전처리는 기존 MViT의 256 리사이즈/224 중앙 크롭이며, 특징 계산용으로 96×96으로 줄인다. 단일 이미지 특징 1,280차원과 움직임 특징 402차원을 연결한 같은 입력 크기를 쓰고 해당하지 않는 특징 부분을 0으로 가린다. 세 대조군의 분류기 구조, 전체 파라미터 수, seed별 초기 가중치, 배치 순서는 같다. 비활성 입력의 연결 가중치가 학습 중 변하지 않는지도 검증한다.

학습은 기존 1,000클립 그대로, 검증은 같은 31영상 18,603시점 전체다. 조향은 원본 정답 STOPPED를 제외한 17,346시점에서 계산한다. 가감속·조향 듀얼 헤드와 두 CE 손실 합을 사용한다.

- seed: 20260910, 20260911, 20260912. 세 방식 × 세 seed, 총 9회.
- 각 12에폭, 1,200업데이트, 유효 배치 10, AdamW lr=0.001, weight decay=0.
- 매 배치는 기존과 같은 10개 라벨 조합을 한 개씩 포함한다.
- 정규화 평균·표준편차는 선택된 학습 1,000클립에서만 계산한다.
- 검증 점수로 에폭·학습률·seed를 선택하지 않는다. 마지막 고정 체크포인트와 세 seed 전체를 보고한다.
- 현재 MViT는 같은 표본/배치/12에폭을 썼지만 아키텍처와 학습률이 다르다. 입력 방식의 효과는 우선 같은 MLP 세 조건 사이에서 비교하며, MViT 차이를 입력 방식만의 인과효과로 해석하지 않는다.

특징 추출은 로컬 CPU 두 작업으로 진행하고 학습은 CPU 2스레드다. 외부 업로드·GPU 신규 실행·제출 모델 교체는 없다. 기존 Stage1/2 세션의 작업을 보존한다.

## 검증 및 한계

특징 사전 검사 PASS: 희소/연속 시점 추출의 정확한 일치, 미래 요청 시점이 이전 특징에 영향을 주지 않음, 동일 이미지의 흐름 0, 움직이는 이미지의 흐름 비영, 단일 이미지 특징 일치. 동일 이미지에서 광학흐름 알고리즘이 만드는 작은 수치 오차는 명시적으로 0으로 처리했다.

전 영상 해시를 기존 GPU 학습 번들과 대조한다. 완료 후 별도 검증기로 원본 라벨·모든 캐시·정규화·마스킹·9개 체크포인트 재로딩 및 전 시점 로짓/지표를 대조한다. 실제 영상 두 개에서는 희소 추출을 별도로 재실행한다.

이 대조군은 고정된 저해상도 특징을 쓰는 작은 모델이다. 단일 프레임 모델 전체 또는 움직임 모델 전체의 성능 상한을 의미하지 않는다. 광학흐름도 도로 구조·원근·주변 차량·추정 오차의 영향을 받으므로 센서 회전의 정답을 직접 입력하는 방식이 아니다. 검증 경로는 반복 사용한 개발용이고, 센서 라벨은 대리값이며 공식 점수가 아니다.
