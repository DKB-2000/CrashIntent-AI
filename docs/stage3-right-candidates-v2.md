## 선정과 출처 분리

CCD 1500영상에서 다음 원본과 같은 youtubeID에 속하는 영상을 모두 제외했다.
기존 무작위12개, 우측후보5개, 복원된 이전 블라인드 후보24개, 휴대전화 검증30개,
공개 CCD예제5개다. 조건 간 중복이 있으므로 단순 합으로 제외 수를 계산하지 않는다.
제외 후722영상/70출처가 남는다. 출처 키는 CCD 메타데이터의 youtubeID이며 실제
차량·카메라 식별자가 아니다. 같은 사고 모음 출처를 묶어 보수적으로 제외하는 방식이다.

각 영상의0,4,8,...,28프레임을160×90으로 줄이고 광학흐름을 계산한다.
x10:150/y25:80 영역의 수평 흐름 중앙값이 음수인 정도로 정렬한다. 자차의 오른쪽 회전
때 배경이 왼쪽으로 흐를 수 있다는 탐색용 지표이며 정답 생성식이 아니다. 앞차 이동,
차선 변경, 충격·카메라 회전에도 반응할 수 있어 육안 선별이 뒤따른다.

상위 후보는 출처마다1영상씩 최대36개를 육안검토한다. 0/8/16/24/32/40 시점의
연속 스틸로 자동차 전방 시점과 방향 변화 가능성을 살피고, 고정 CCTV·이륜차·옆/후방
시점·뚜렷한 좌회전·전도만으로 순위가 높아진 영상은 제외한다. 애매한 경우 확정
우회전으로 표현하지 않으며 최종 구간별 라벨은 사용자가 판정한다.

출처 분리는 기록된 제외 집합과의 분리를 의미한다. 전체 Stage1/2 학습 출처와의 분리나
독립 일반화를 인증하는 것은 아니다. 의도적으로 회전 후보를 고른 편향된 진단셋이다.
기존 모델 예측은 후보 선정과 검토 페이지에 사용하지 않는다.

## 실행과 산출물

`src/prepare_stage3_right_candidates_v2.py`가 단일실행 OS잠금,10분 제한,재시도0회,
상태·로그 저장을 수행한다. 감시기가 worker를 실행하고 실패·시간초과를 기록한다.
Codex가 완료 대기만 남은 상태에서 반복 조회하지 않는다.

산출물은 `artifacts/stage3-right-candidates-20260914/`에 저장한다.
plan.json은 입력해시와 제외집합, ranking.json은 탐색순위, shortlist.json과screen-*.jpg는
육안검토 후보, visual-screening.json은 선별 판단 기록이다. source_id는6자리 CCD 원본ID,
youtube_id는같은출처 제외용 키로 구분한다.

선별 후 `src/package_stage3_right_candidates_v2.py`가 원본해시·영상10fps·전50프레임,
기존출처제외·후보끼리출처중복없음을 검사하고 영상 사본과 시청페이지를 만든다.
사람검수 저장위치는 `data/stage3-right-review-v2/`이며 모든 프레임은 처음에
UNKNOWN/UNKNOWN, reviewed=0으로 기록한다. 선정 이유를 사람 정답으로 복사하지 않는다.

검수할 때 `scripts/Start-Stage3RightReviewV2.ps1`을 실행한다. 기존 검수셋과 경로가
달라 CASE_01이나 REVIEW_011 라벨에 영향을 주지 않는다. GUI를 자동으로 열지 않는다.
시청용 review.html에는 라벨 저장 기능이 없다. 검수 후에만 모델을 채점한다.

최신 상태는 같은 결과 폴더의 status.json과 validation.json을 따른다.
READY_FOR_HUMAN_REVIEW는 자료 준비 완료이며 확정 우회전 확보 완료가 아니다.
