# Stage2 3번: CCD 충돌 사전학습 대조 (2026-09-10)

> 현재 상태 (2026-09-11): 완료·독립 검증 PASS. 사전학습 후보의 공식 점수 하락 이후 판단은 [다음 작업](stage2-next-steps.md)을 우선한다.

사용자가 2번 완료 후3번 진행을 승인했다. 현재 CPU 특징 추출 실행 중이며 학습 결과는 아직 없다.

## 출처 분리

CCD1500영상 중 기존 수동66영상의23출처 전체를 제외했다.
사전학습은1296영상/110출처. 모든 원본 파일 실재 및 사전학습/수동 영상 ID·출처 중복 없음 확인.
각 fold만 제외하는 방식보다 보수적으로 모든 수동 출처를 제외하여 사전학습 모델을 공유한다.
사전학습 라벨은 CCD binlabels에서 최초1의 프레임으로 변환한 충돌 onset proxy다.
진입/회피/방향 라벨을 새로 만들지 않는다. 원본과 특징별 해시를 남긴다.

## 고정 대조

1. 기존 ImageNet ResNet18 가중치·동일 전처리로1296영상의 모든 프레임 특징을 CPU 추출.
2. MViT가 아닌 Stage2 BiGRU와 충돌 head만3에폭 사전학습(lr2e-4, gaussian sigma1).
   진입·scene head는 초기 상태가 유지됐는지 텐서 단위로 검사한다. 총3888업데이트.
3. 기존5출처 분할에서 scratch vs pretrained를 각각15에폭 soft_mixed 설정으로 미세조정.
   같은 초기 진입·scene head, 같은 dropout seed·영상순서·장면혼합 선택·AdamW 초기화 조건.
   pretrained만 BiGRU·충돌 head가 사전학습 상태다. 평가 분할로 에폭을 고르지 않는다.
4. 저장 모델 재로딩 및 독립 검사. 단일 seed의 탐색적 개발 비교이며 공식점수는 아니다.

현재 scratch RNG 설정은 과거CV 초기화 후 RNG 소비 순서와 다를 수 있어 이번에 scratch도
새로 실행한다. 기존 .4508을 새 대조군 대신 쓰지 않는다. 두 arm 결과의 차이를 비교한다.
사전학습 업데이트 증가와 외부 데이터 효과를 완전히 분리하는 동일업데이트 대조는 포함하지 않는다.
