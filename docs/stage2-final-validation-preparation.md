## 입력과 시각

`data/stage2-validation-nexar-20260914/images/NEXAR_XXXXX/frame_000000.jpg` 형식으로
모든 프레임을0번부터 저장한다. 원본 크기 유지/JPEG q2, 사건시각 크롭·FPS변환 없음.
이는 자체 구성한 검증 이미지이며 대회 비공개 평가 이미지와 동일한 인코딩이라는 뜻은 아니다.

공간부족·디코딩실패 시 부분결과 보존 후 실패기록하며 자동무한재시도하지 않는다.

`frame-maps/<ID>.csv`에 파일명·SHA256·바이트·크기·정수PTS·유리수time_base와
첫PTS를 저장한다. 채점은 `(pts-first_pts)*time_base_num/time_base_den`을 정확한
분수로 계산하며, 명목 FPS나 프레임번호/30을 사용하지 않는다. 반올림초는 화면표시용이다.
이 매핑은 각 영상의 첫 디코딩프레임을0초로 둔다. 프레임번호는 해당원본 디코딩순서와 일치한다.
원본50개 해시, 모든JPEG 전체디코딩·해시·연속번호·PTS단조증가를 검사한다.

## 사람 검수는 준비가 끝난 뒤

준비완료 후 `data/stage2-validation-nexar-20260914/review.html`을 브라우저로 연다.
프레임좌우이동·번호/실제시각표시·충돌/진입기록·회피/방향·제외사유·검수자 입력을 제공한다.
AI 의심분류·Nexar event 참고시각·모델예측은 표시하지 않는다. 선정단계에 AI관찰이
있었다는 사실은 유지하며 완전한 미열람 블라인드 표본이라고 주장하지 않는다.

`review-decisions.csv`는50행 모두PENDING, 정답4열은빈칸으로 시작하는 작업지다.
이 파일을 정답라벨50개로 계산하지 않는다. 웹화면은 브라우저 임시저장만 하므로 중단 시
CSV를 내려받아 보관한다. 기존 CSV를 다시 불러와 이어서 검수할 수 있다.
내려받은 `stage2-review-decisions.csv`를 프로젝트 내 별도 위치에 보관하고 명령의
`-Labels`로 지정한다. 기존 작업지를 자동덮어쓰지 않는다.

모든50개를 ACCEPT 또는 EXCLUDE로 결정해야 최종채점 가능하다. ACCEPT에는 검수자와
4개 유효정답이 필요하고 EXCLUDE에는 검수자·제외사유가 필요하다. 모호하면PENDING으로
남기거나 근거를 적어 제외한다. 촬영출처 불명은UNKNOWN 유지, 임의로영상ID를 출처로 넣지 않는다.
유효30개미만이면 점수는 부족표본 진단으로 표시하고 최종목표달성으로 보지 않는다.

## 고정 비교·채점

비교모델은 현재 기준 `soft_mixed_scene/best.pt`와 이전제출 CCD사전학습 최종모델 두 개다.
사전학습모델은 공식하락을 보인 비교대상으로, 새로 승격한후보가 아니다. CV의 최고fold나
이번미채택 지역/움직임head를 선택하지 않는다. 기존 체크포인트를 복사·해시고정하고,
보관된 실제제출 추론클래스를 사용한다. ResNet도 로컬동일가중치이며 인터넷다운로드가 없다.

CPU FP32, 두모델에동일JPEG·ResNet특징·전체프레임 입력. 사람검수완료 gate 전에는
후보추론을 거절한다. 모델스모크는 기존개발3영상특징과 공개예제3JPEG에서만 수행한다.
최종규약은 `evaluation-contract.json`으로 입력·모델·코드해시와 함께 라벨작성 전에 고정한다.

채점기는 두시점 ±0.3초 정확도, 회피·방향 정확도와 네항목단순평균을 별도로 제공한다.
이는 로컬진단지표이며 비공개 공식산식을 재현했다고 주장하지 않는다. 누락예측/음수·분수·
범위밖프레임/비수치·잘못된범주는 해당항목오답, 중복·알수없는ID는 입력오류로 거절한다.
PENDING이나잘못된사람라벨은 채점하지 않는다. 제외영상은분모에서빠지고제외건수를보고한다.
출처동일가중은 알려진촬영출처만계산하고포함영상/그룹수를명시한다. UNKNOWN을 독립출처로
간주하지않으며 모든출처불명이면 출처지표는null이다.

검수 후 실행(지금은 실행하지 않음):

```powershell
./scripts/Start-Stage2FinalComparison.ps1 -Labels data/stage2-validation-nexar-20260914/review-decisions.csv
```

내려받은별도CSV를사용하면 `-Labels`만 해당경로로바꾼다. 입력/라벨검사를 먼저 실행하고
통과 시숨김감시기에서최대2시간CPU추론·CSV재읽기채점·동일라벨해시검사를 수행한다.
중복잠금/단일시작마커/재시도0, 결과는 `artifacts/stage2-final-comparison-20260914/`.
