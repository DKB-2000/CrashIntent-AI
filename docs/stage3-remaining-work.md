# Stage3 남은 개선 사항과 사용자 검수

기준일: 2026-09-11. 최신 인수인계와 로컬 결과를 정리한 현황 문서다.

## 현재 모델과 완료한 실험

유지 대상은 **1·5·15프레임 시간창의 광학흐름 특징을 사용하는 움직임 MLP**다.
사용자 보고 공식 Stage3 최고점은 **0.4187467089**이며 제출 86809와 87406에서 동일했다.
짧은 시간창 후보의 제출 87243 점수는 0.4141711429였다.
공식 Stage3는 주행 중 조향 Macro-F1이므로 가감속 개선만으로 후보를 승격하지 않는다.

| 완료한 경로 교차검증 | 조향 F1, 3 seed 평균 | 판단 |
|---|---:|---|
| 기존 1/5/15 움직임 MLP | 0.718900 | 기준 유지 |
| 짧은 시간창 | 0.709580 | 미채택 |
| 변화량·방향 파생특징 추가 | 0.682605 | 미채택 |
| 작은 시간축 CNN | 0.705620 | 미채택 |

동일 17경로·1000균형클립·5분할 개발 교차검증이며 공식 점수나 새로운 출처의
자연주행 성능은 아니다. 각 실험은 완료 및 독립 검증 PASS 상태다.
CNN은 과거 흐름 순서·구성에 민감했지만 기존 MLP를 넘지 못했다.
단순 재실행이나 추가 에폭 학습이 다음 확정 작업은 아니다.

라벨 생성식·영상 시간 대응 감사도 완료했다. 전체 좌우 반전이나 일괄 시간 이동을
적용할 근거는 확보되지 않았다. 센서 대리 라벨과 공식 범주의 의미 동등성은 미확정이다.

## 남은 작업, 우선순위 순

| 순서 | 작업 | 담당과 완료 조건 |
|---|---|---|
| 1 | 준비된 24영상 블라인드 검수 | 사용자가 자차 조향·주행 상태를 판정하고 저장. 확인 시점 1200프레임 전부 reviewed=0 |
| 2 | 사람 정답으로 기존·짧은 창 모델 비교 | Codex가 두 모델에 같은 유효 시점을 적용하고 무작위/진단 표본을 분리 채점 |
| 3 | 조향 기준과 어려운 구간 재검토 | 사용자가 완만한 곡선·차로 변경·전환 경계를 재확인. 불확실하면 UNKNOWN 유지 |
| 4 | 다른 출처와 주행 조건 보강 | 자연주행·도시·정지 재출발·다른 차량을 보강하고 출처 분리 검증 |
| 5 | 실패 유형에 맞춘 다음 모델 실험 | 사람 검수와 경로별 오답 근거로 설계를 먼저 고정. 다음 구조·학습 방식은 아직 미확정 |
| 6 | 개선 후보 제출 검증 | 개선 근거 확보 후 ZIP 생성, CPU/GPU 출력·통합 검사, 사용자 제출 및 점수 기록 |

CCD 24영상은 각 5초의 사고 영상이므로 공식 실차 계측 분포나 일반 자연주행을
대표하지 않는다. 다른 차량의 comma2k19 청크와 ZOD 도시 주행 보강은 남은 후보지만,
대량 확보 전에 실제 부족한 조건과 라벨 품질을 확인해야 한다.
**ZOD는 기록상 접근 승인 대기**다. 승인 메일 수신 여부는 사용자가 확인해야 한다.

## 사용자가 직접 할 일

프로젝트 루트 PowerShell에서 실행한다.

```powershell
.\scripts\Start-Stage3BlindComparison.ps1
```

1. 영상창을 클릭하고 영문 입력 상태로 조작한다. 첫 구간 저장 후 종료·재실행하여
   라벨이 복원되는지 확인한다. 실제 GUI 키 조작은 사람 확인이 남아 있다.
2. 첫 12개(REVIEW_001~012)를 먼저 검수한다. 모델 예측 전에 고정한 무작위 표본이다.
3. 나머지 12개(REVIEW_013~024)는 모델 불일치 진단 표본이다. 전체 성능 표본과 구분한다.
4. 카메라가 달린 차량의 진행 방향과 주행/정지를 판정한다. 앞차 이동을 자차 회전으로
   해석하지 않고 전후 영상을 본다. 예측·선정 점수는 검수가 끝나기 전에 열지 않는다.
5. 완만한 곡선·차로 변경·회전 시작/끝을 다시 확인한다. 가림·충격·고정 CCTV 등으로
   판단이 어려우면 UNKNOWN으로 남긴다. 가능하면 다른 사람이 독립 재검수한다.

| 키 | 기능 |
|---|---|
| SPACE | 재생/정지 |
| I / O | 구간 시작/끝, 양 끝 프레임 포함 |
| 1 / 2 / 3 / 0 | LEFT / STRAIGHT / RIGHT / UNKNOWN |
| M / T / U | MOVING / STOPPED / UNKNOWN |
| S | 구간 저장 |
| N / B | 다음/이전 영상 |
| A / D | 이전/다음 1프레임 |
| J / K | 이전/다음 10프레임 |
| Z | 현재 영상 마지막 저장 구간 취소 |
| Q | 종료 |

저장 위치는 `data/stage3-blind-review-20260911/labels/annotations.json`과
`labels_review.csv`다. S로 저장한 구간은 즉시 기록되며 같은 명령으로 재개할 수 있다.
검수가 끝난 뒤 아래 명령으로 비교하거나 Codex에 저장 완료를 알린다.

```powershell
.\scripts\Start-Stage3BlindComparison.ps1 -Score
```

사람이 MOVING으로 판정하고 조향을 확정한 시점만 채점한다. 미검수·정지·UNKNOWN은
두 모델에서 똑같이 제외한다. 사람이 검수한 정답이 없으면 점수를 생성하지 않는다.
클래스별 표본 수·미확정 비율·부분 검수 여부를 함께 해석해야 한다.
센서 없는 영상에서 가감속이나 정량 속도 정답을 임의로 만들지 않는다.

공개 Stage3 예제 5개는 도구 연습·기준 합의용이며 독립 검증셋은 아니다.
해당 도구는 `scripts/Start-Stage3HumanReview.ps1 -Assume10Hz`로 실행한다.
`-Assume10Hz`는 확인된 공개 예제 FPS 헤더 오류 대응용이며 임의의 30fps 영상에 쓰면 안 된다.

## 후속 판단 조건과 자료 위치

- 확정 사람 라벨·출처 목록을 버전으로 고정한다. 학습에 넣은 뒤에는 독립 검증으로 취급하지 않는다.
- 좌·직진·우 재현율과 경로별 결과를 함께 비교한다. 짧은 창이 항상 직진 편향이라는 설명은 경로 교차검증에서 지지되지 않았다.
- 개발 점수 상승만으로 공식 개선을 확정하지 않는다. 새 후보의 실제 제출 결과를 별도 기록한다.
- 장시간 실행은 watcher/예약의 결과 기록을 사용하며 Codex가 반복 대기·상태 조회하지 않는다.

공식 제출 점수 원기록은 `docs/submission-history.md`, 최신 상세 작업 기록은
`CODEX_HANDOFF.md`의 2026-09-11 완료 항목에 있다. 로컬 결과는
`artifacts/stage3-route-cv-20260911/`, `artifacts/stage3-dynamics-cv-20260911/`,
`artifacts/stage3-sequence-cv-20260911/`에 보관한다.
검수 영상·라벨·실험 산출물은 이 문서 커밋에 포함되지 않으므로 다른 PC에서는 별도 복원이 필요하다.
