# Stage3 기존·짧은 시간창 블라인드 검수

2026-09-11. 사용자에게 확인한 결과 실제 사람 검수 라벨은 아직 없다. 정답을 만들거나 성능 점수를 계산하지 않고 검수 자료를 준비했다.

## 시작

프로젝트 PowerShell에서 실행:

```powershell
.\scripts\Start-Stage3BlindComparison.ps1
```

영상창 클릭 후 영문 입력 상태로 사용한다. SPACE 재생/정지 → I 구간 시작 → O 구간 끝 → 1좌/2직진/3우/0불명확 → M주행/T정지/U불명확 → S저장. N 다음 영상, Q 종료. Z로 현재 영상의 마지막 저장 구간을 취소한다. 자동저장되며 같은 명령으로 이어서 검수한다.

카메라가 달린 차량의 진행 방향을 판정한다. 앞차 이동을 자차 회전으로 보지 않는다. 일정한 회전이 지속되는 구간, 직진과 출발·정지를 먼저 확인한다. 단순히 도로가 휘어 보이는 한 프레임으로 결정하지 말고 전후 영상을 본다. 모호한 방향, 고정 CCTV나 자차가 아닌 시점, 카메라 충격·편집으로 판단이 어려운 구간은UNKNOWN으로 남긴다. 저속 여부나 실제 m/s는 이 영상에 센서정답이 없으므로 추정치를 정량 정답으로 사용하지 않는다.

영상을 합치면 약2분이지만 프레임/구간 판정에는 추가 시간이 든다. 24개를 한 번에 끝낼 필요는 없다. 먼저 첫12개를 검수하고, 다음12개는 별도 진단용으로 본다. 예측·선정 점수 파일을 열기 전에 판단을 마쳐야 한다.

## 구성

기존 승인된 CCD1500 원본 중 36개 source_id에서 한 영상씩을 고정 seed20260911로 선정했다. 공개baseline5영상과 같은 원본출처 및 Stage1 휴대전화holdout 영상과 같은원본출처는 제외했다.

- REVIEW_001~012: 모델예측을 보기 전에 뽑은 출처별무작위12영상.
- REVIEW_013~024: 나머지24영상에서 기존회전/short직진 불일치 수를 우선해 고른12진단영상. 실제로 회전·직진이라는 정답을 뜻하지 않는다.
- 24개는 서로다른CCD원본출처ID, 각50프레임/10fps. 원본바이트를복사해해시유지. 인코딩·리타이밍없음.
- Stage3학습comma2k19와다른자료이지만CCD는Stage1/2에서쓰일수있고,사고5초클립이라공식분포나일반자연주행을대표하지않는다. 원본출처ID는CCD메타데이터 기준이며실제촬영자독립성을추가확인한것은아니다.
- 출처·이용조건은 기존 `DATA_SOURCES.md` CCD기록을따른다. 새로운다운로드·업로드없음.

## 저장·비교

영상 `data/stage3-blind-review-20260911/videos/`, 라벨 `data/stage3-blind-review-20260911/labels/annotations.json` 및 `labels_review.csv`.

검수가 끝나면:

```powershell
.\scripts\Start-Stage3BlindComparison.ps1 -Score
```

사람이 MOVING이며 조향을 확정한시점만 두모델에동일하게적용한다. 무작위표본과불일치진단표본 점수는분리해계산한다. 일부만검수하면부분집합결과로표시한다. 정지/UNKNOWN/미검수는채점하지않고,사람정답이0개면WAITING_FOR_HUMAN_LABELS로끝내며점수를만들지않는다. 클래스별지원표본이없는경우고정3클래스F1해석에주의한다.

모델예측은검수UI에표시하지않는다. 점수/출처매핑/선정정보는 `artifacts/stage3-blind-review-20260911/`에별도보관한다. 비교모델은실제제출두개와같은seed20260910이며,짧은창예측을검수라벨로자동복사하지않는다. 이도구는속도라벨을수집하지않으므로정량저속성능을확정하지않는다.

준비검증:24개영상사전검사/출처고유성/원본해시/1200시점미검수상태,정답없는채점차단을확인했다. 자세한검증은같은artifact폴더validation.json. GUI키입력은사람의실행을통해확인할단계다.
