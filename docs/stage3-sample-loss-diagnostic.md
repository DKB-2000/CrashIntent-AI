# Stage3 직진 정답 상실과 제거 표본 비교

2026-09-14, 저장된 예측·특징·센서 자료만 사용했다. 추가 학습은 실행하지 않았다.

## 확인된 결과

검증 주행 직진 8,654시점에서 기존 정답을 새 모델이 놓친 수는 시드별 806/1,125/1,024개, 반대로 새로 맞힌 수는 735/587/491개다. 두 시드 이상에서 정답을 잃은 시점은 762개이고 31개 영상 모두에 분포한다. 연속 구간은 518개, 최장 7시점으로 특정 긴 구간 하나에 집중된 현상은 아니다.

제거된 학습 직진 84개 중 59개(70.2%)는 회전 라벨 전후 1초 이내, 40개(47.6%)는 회전 라벨 종료 후 1초 이내였다. 유지된 216개에서는 각각 40.3%, 28.7%다. 제거된 84개 중 62개는 pose yaw의 중간 범주였고, 11시점 연속 직진 조건을 만족한 것은 37개(44.0%)였다. 안정적인 표본 선별이 전환에 가까운 표본을 많이 제거했다는 사실은 확인된다.

검증에서 기존 정답 중 새 모델이 놓친 비율은 다음과 같다. 세 시드의 예측 건수를 합친 값이며 독립 표본 수나 통계적 유의성을 의미하지 않는다.

| 조건 | 기존 정답 수 | 잃은 정답 수 | 상실 비율 |
|---|---:|---:|---:|
| 회전 라벨 종료 후 1초 이내 | 2,430 | 714 | 29.4% |
| 나머지 | 12,403 | 2,241 | 18.1% |
| 회전 라벨 전후 1초 이내 | 4,290 | 1,116 | 26.0% |
| 전환에서 1초 초과 거리 | 10,543 | 1,839 | 17.4% |

전환에서 먼 구간에서도 순손실이 654건으로 발생했다. 저속 5m/s 미만에서는 기존 정답 214건 중 150건 상실(70.1%)했지만 이 속도 구간의 학습 표본은 교체하지 않았다. 따라서 직접 제거된 상황만으로 전체 변화를 설명할 수 없다. 학습 가중치와 학습 표본 기반 정규화가 모두 달라진 대조 실험이다.

두 시드 이상 정답 상실 집합의 흐름 크기 p90 중앙값은 1.575로, 모든 모델이 맞힌 집합의 1.763보다 작았다. 제거/유지 학습 표본도 각각 2.119/2.109로 유사했다. 큰 주변 움직임만이 공통 원인이라는 근거는 없다. 격자 optical flow는 주변 차량 검출이나 곡선도로 판별 결과가 아니다.

## 판단과 다음 조건

전환에 가까운 직진을 보존할 이유는 확인했지만, 이를 보강하면 성능이 오를 것까지 확인한 것은 아니다. 기존 모델을 유지한다. 다음 대조를 설계한다면 기존 1,000개를 보존하고 학습 경로 내부에서 전환 표본의 부족과 중복 정도를 먼저 확인해야 한다. 이번 검증 오답 영상을 학습 자료로 옮기지 않는다. 이 분석만으로 새 학습은 시작하지 않았다.

결과 폴더는 `artifacts/stage3-sample-loss-diagnostic-20260914`이다. `validation-straight.csv`, `training-straight.csv`, `stratified-losses.csv`, `loss-runs.csv`, `report.json`을 저장했다. 고정 라벨 재구성, 6개 예측 파일 해시·시점 대응, 특징 캐시 해시, 84/216 분할 및 손실 건수 합계를 검증했다. 라벨 전환은 센서 라벨 기준이며 사람이 확인한 실제 회전 시점이 아니다.
