# Stage3 사람이 만드는 조향 검증셋 안내

## 시작하기

프로젝트 폴더에서 PowerShell을 열고 아래 명령을 실행하세요. 영상창을 클릭한 뒤 영문 입력 상태에서 키를 누릅니다.

```powershell
.\scripts\Start-Stage3HumanReview.ps1 -Assume10Hz
```

기본 영상은 `Baseline/data/stage3/videos`의 공개 예제5개입니다. 예제의 FPS 헤더 오류 때문에 위 명령은 확인된10Hz 시점 규격을 명시합니다. 실제 영상 변환은 하지 않습니다. 이5개는 도구 연습과 기준 합의용이며, 독립적인 일반화 검증셋이 아닙니다.

별도 수집한 **10fps MP4** 폴더로 시작하려면:

```powershell
.\scripts\Start-Stage3HumanReview.ps1 -VideoDir 'data/stage3-human-videos' -OutputDir 'data/stage3-human-validation'
```

임의의30fps 영상에 `-Assume10Hz`를 사용하면 시간이 틀어집니다. 새 영상은 원본을 보존하고 별도10fps 사본을 준비하세요. 원본의 실제FPS가 불명확하면 먼저 확인해야 합니다. 파일명은 영상의 고유ID입니다. 작업 중 영상 파일을 바꾸면 해시 검사로 재개가 거부됩니다. 한 저장폴더는 같은 입력영상 목록으로 계속 사용하세요.

## 한 구간 기록하는 순서

1. SPACE로 재생/정지. 먼저 전후 몇 초를 보며 **카메라가 달린 차량**의 움직임을 확인합니다.
2. 시작 프레임에서 I, 끝 프레임에서 O. 양 끝 프레임을 모두 포함합니다.
3. 조향: 1=LEFT, 2=STRAIGHT, 3=RIGHT, 0=UNKNOWN(판단불가).
4. 운동 상태: M=MOVING(움직임), T=STOPPED(정지), U=UNKNOWN(불명확).
5. S를 눌러 구간 저장. JSON과 CSV가 즉시 저장됩니다.
6. 다음 구간도 같은 방법으로 기록. N=다음영상, B=이전영상, Q/ESC=종료.

A/D는 이전/다음1프레임(0.1초), J/K는 이전/다음10프레임(1초)입니다. 재생은 시각 검수용 근사10fps이고, 판정 시간은 항상 프레임번호/10 기준입니다.

Z는 **현재영상에서 마지막으로 저장한 구간**을 취소하고 즉시 저장합니다. 구간이 겹치면 저장을 거절합니다. 이전 구간을 고치려면 필요한 만큼Z로 되돌린 뒤 다시 기록합니다. 종료 후 같은 명령으로 재개하면 저장한 구간은 복원되지만 커서는 첫영상0프레임에서 시작합니다. S를 누르지 않은 선택은 저장되지 않습니다.

## 판단 기준: 우선 합의할 개발용 기준

공식 안내는 LEFT/STRAIGHT/RIGHT 범주를 제시하지만 완만한 곡선·미세 보정의 세부 경계는 확인되지 않았습니다. 아래는 **우리 개발 검증을 위한 임시 기준**이며 공식 정답을 대신하지 않습니다. 일단 기준을 정하면 모델 점수를 보고 바꾸지 마세요.

- LEFT/RIGHT: 자차의 진행 방향이 해당 방향으로 바뀌는 구간. 도로 곡선 추종도 방향 변화가 분명하면 기록하되, 교차로 회전과 구분해 메모합니다.
- STRAIGHT: 자차 진행 방향이 대체로 유지되는 구간. 화면의 도로 위치 한 장만 보고 결정하지 말고 시간순 차로·도로 경계를 봅니다.
- UNKNOWN: 미세한곡선과 직진을 구분하기 어렵거나 카메라진동·가림 때문에 확신할 수 없는 구간. 억지로세범주에 넣지 않습니다.
- 차로변경: 차가 옆차로로 이동한다는 이유로 전체를 한방향으로 묶지 마세요. 방향 전환과 복귀가 있을 수 있습니다. 구간별 판정이 어렵다면UNKNOWN.
- MOVING/STOPPED: 자차와 도로·고정물의 상대움직임을 확인합니다. 앞차가 멈췄다고 자차도 정지로 판단하지 않습니다. 정지에서 조향은UNKNOWN으로 남겨도 됩니다.
- 주변차량의 이동, 소실점의 좌우 위치, 핸들각도 센서값 하나만을 근거로 정답을 만들지 않습니다.

라벨 전환 전후는0.1초씩 확인하고, 전환 경계가 애매하면 짧은UNKNOWN 구간을 둡니다. 먼저 예측값·기존센서라벨을 보지 않고 판정하세요. 도구에는 모델 예측을 표시하지 않습니다.

## 검증셋 구성과 두 번 확인

처음에는 모델 학습에 쓰지 않은10~20개 영상을 목표로 합니다. 여러원본출처에서 주간/야간, 직진, 좌우곡선, 뚜렷한회전, 정지재출발을 포함하세요. 한 긴 영상의 조각을 서로 독립적인 출처로 세면 안 됩니다. 같은원본의 조각은 모두 같은분할에 둡니다.

- 공개적으로 사용 가능한 영상만 사용하고 URL·출처·이용조건·원본ID를 별도목록에 남깁니다. `docs/templates/stage3-human-sources.csv`를 복사해 작성하세요.
- 비공개대회평가 영상은 검증셋 구축이나 라벨링에 사용하지 않습니다.
- 희귀좌우구간을 의도적으로 모은 진단셋과 자연분포검증셋을 구분합니다. 클래스수와UNKNOWN 비율을 점수와 함께 보고합니다.
- 1차판정 뒤 어려운구간을 나중에 다시 확인하거나 다른검수자가 독립판정합니다. 의견이 다르면 메모 후UNKNOWN을 유지합니다.
- 확정본의 annotations.json, labels_review.csv, 출처목록을 복사해버전을 고정합니다. 검증셋을 학습에 넣으면 이후 점수는 독립검증으로 취급하지 않습니다.

## 저장 파일과 전달 방법

기본 저장위치: `data/stage3-human-review/`.

- `annotations.json`: 영상경로·SHA256·총프레임·구간별조향/운동상태. 재개에 필요합니다.
- `labels_review.csv`: 모든시점의ID,sample_index,steer_label,motion_status,reviewed,valid_steer.
- 미검수와UNKNOWN은 정답으로 취급하지 않습니다. `valid_steer=1`은 사람이MOVING으로 판단하고 조향도확정한시점만 뜻합니다.

조향 검증용이라 가속/감속 정답을 지어내지 않습니다. 이CSV는 대회제출형식이 아닙니다. 작업후 **저장폴더 경로와 출처목록**을 알려주면 모델대조를 진행할 수 있습니다.

원본 및 저장구간 사전검사(화면없이):

```powershell
.\.venv\Scripts\python.exe src/review_stage3_human.py --check --assume-10hz --output-dir data/stage3-human-review
```

모델예측CSV를 확보한뒤 채점:

```powershell
.\.venv\Scripts\python.exe src/score_stage3_human.py --labels data/stage3-human-review/labels_review.csv --predictions artifacts/my-stage3-predictions.csv --output artifacts/stage3-human-score.json
```

정지제외는 **사람의 motion_status**로 결정하며 모델의STOPPED 예측으로 점수를 유리하게 만들지 않습니다. UNKNOWN/미검수시점 제외범위는 두모델에 똑같이 적용합니다. 채점은 고정3클래스Macro-F1이며 정답이 없는클래스도0으로 계산될 수 있으므로 class_support를 확인하세요.

구간포함경계·중복거절·UNKNOWN/정지제외2테스트PASS. 실제공개5영상5992시점의입력·저장파일사전검사PASS. GUI창의사용자키입력은자동검사하지 않았습니다. 한글텍스트표시환경차이를 피하려고 영상창의안내는영문입니다.
