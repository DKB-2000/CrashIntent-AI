## 고정 구성

기존 화질균형 학습과 동일한 85출처의 원본85개를 사용한다.
기존 train/val 및 phone holdout·동일출처 형제 제외를 원래 CCD 분할과 다시 대조한다.
검증21출처·실패분석7원본을 학습에 추가하지 않는다.

- 화질3조건: clean / noise / quality_mix.
- 화면단서3조건: 7종 화면효과를 중립값 대비25%로 약화 / 원근·스케일 제거 / 깜박임 제거.
- 원본마다3×3=9개, 총765개 RERECORDED 생성. 50프레임씩 총38250프레임.
- 기존의 동일85출처×3화질 ORIGINAL255개는 해시·전프레임 재검사 후 참조 재사용.
- 기존 full재녹화와 동일seed/화질/CRF24를 유지해 화면효과 차이를 분리한다.
- 원본과 재녹화의 noise_sigma/blur_sigma/jpeg_quality는 같은profile에서 일치한다.
- clean은 노이즈·블러·JPEG가 모두 중립이어서 무노이즈 재녹화도 포함한다.
  모든 화면단서를 제거하고 재녹화라고 강제하는 조건은 만들지 않는다.

새1020행 manifest는 원본255/재녹화765로 파일수가 불균형하다. 추후 학습 때는
파일수 비례 샘플링 대신 원본/재녹화4:4의 균형배치와 profile별 원본쌍을 유지해야 한다.
기존510영상 또는 혼합데이터와의 조합·학습 일정은 데이터 검증 이후 사전 고정한다.
