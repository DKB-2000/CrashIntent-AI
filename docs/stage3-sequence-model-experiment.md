# Stage3 15흐름 시간축 모델 실험

2026-09-11 사용자2번실행요청. 기존1.5초문맥은유지하고,요약평균을입력하던MLP 대신 과거15개프레임쌍의134차원광학흐름을순서대로입력하는작은CNN을비교한다. 센서·사람정답추가·공식평가파일사용없음.

## 고정 설계

- 입력1000×15×134. 134는8×8 xy흐름128+크기통계4+평균xy2. 이전평균캐시에는개별15흐름이없어학습156영상의필요한16프레임구간만재추출한다.
- Conv1d134→32,k3,padding1→ReLU→Conv32→32,k3,padding1→ReLU. 마지막위치와시간평균을붙인64차원→Linear64→64,ReLU→가감속4/조향3heads. 파라미터20615개. 과거클립안에서만연산하며평가시점뒤프레임은없다.
- 기존MLP는224135개파라미터로구조·용량·정규화방식이달라결과차이를시간순서만의인과효과로해석하지않는다. 작은시간모델의실용성대조다.
- 이전과동일17경로/1000균형클립/5fold/3seed20260910~12/1200updates/같은저장배치10/AdamW .001/weight_decay0/gradientclip1/CPU2threads. 평균표준편차는각fold학습클립의과거15흐름에서만134채널별계산(std최소.01,clip±10).
- 기준MLP15개는검증완료원본CV를재사용하며CNN15개를신규학습한다. 마지막고정체크포인트와전3seed를보고하며fold/seed/epoch를최고결과로선택하지않는다.
- 기존4개개발검증경로는이번비교에사용하지않는다. 기존균형표본의경로CV이며새로운실세계/자연분포성능이아니다.

## 순서 의존성 진단

동일학습모델의검증입력만3조건으로평가한다.

1. ordered:원래15흐름.
2. shuffle_past:현재흐름은유지하고과거14개순서만고정난수로섞음. 표본간정보혼합없음.
3. repeat_current:현재흐름을15회반복.

모델입력을분포밖으로바꾸는진단이므로순서효과의완전한인과증명이나별도학습대조군은아니다. 섞은조건으로모델선택/재학습하지않는다.
