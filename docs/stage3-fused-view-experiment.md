## 비교 목적과 고정 조건

앞선 전체 화면 대체 실험은 조향 Macro-F1이 0.718900에서 0.642716으로 하락했다.
이번에는 중앙 영상의 세부 정보를 그대로 두고 전체 화면의 움직임을 함께 제공한다.
검증을 통과한 이전 실험의 156영상 특징 캐시를 재사용하며 캐시·메타데이터·코드·
기준 모델·표본·저장 배치의 SHA256을 학습 전 plan.json에 고정했다.

| 조건 | 활성 입력 |
|---|---|
| baseline | 중앙 402차원, 기존 위치 1280:1682 |
| fused | 중앙 402차원 보존 + 전체 화면 402차원을 878:1280에 추가 |

1682→128→64 및 가감속4/조향3 head 구조, 초기값 seed, 전체 할당 파라미터 수는 같다.
다만 활성 입력이 402에서 804차원으로 증가하여 실제 학습에 기여하는 가중치가 늘어난다.
주변 시야의 효과만 분리한 실험으로 해석하지 않는다. 중앙 특징 보존·전체 특징 위치·
비활성 입력 0·원본 배열 불변 검사를 통과했다.

기존 1000클립/17경로의 5fold, seed 20260910/11/12, 저장된 균형 배치10×1200업데이트,
AdamW lr 0.001/weight_decay 0, gradient clip 1, FP32 CPU 2스레드를 사용한다.
각 fold의 학습 자료만으로 정규화하며 마지막 모델을 평가한다.
새 모델 15개를 학습하고 기준 모델 15개는 재사용한다. 기준 모델 exact 재학습은
직전 전체 화면 실험에서 통과했으며 이번에는 15개 모두 체크포인트와 로짓을 재검증한다.

## 검증과 판정

경로 분리·학습 정규화·30모델 저장 로짓·OOF 완전성을 검사하고 CSV에서 혼동행렬과
조향 F1을 별도 계산한다. 3seed OOF F1 모두 개선, 5fold 중 4개 이상 평균 개선,
방향별 평균 재현율 하락 2%p 이내를 모두 만족하면 후속 후보로만 분류한다.
seed나 fold를 골라 보고하지 않는다. 센서 proxy 균형 표본의 반복 개발 평가이며
사람 검수 및 공식 평가를 대체하지 않는다. 보류된 사람 검수 자료는 사용하지 않는다.
