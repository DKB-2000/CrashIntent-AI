## 고정 실험 계획

기존 수동 라벨 중 승인된66영상과 검증된 ImageNet ResNet18 특징 캐시를 사용한다.
보류8건을 새로 포함하지 않는다. 캐시와 원본 분할 CSV SHA256을 이전 독립 검증과 대조했다.
원본 유튜브 출처 전체를 묶고 영상 수가 균형을 이루도록5개 분할을 만들었다.
각 영상은 학습에 포함되지 않은 모델로 정확히 한 번 평가한다.

- exact_5: 기존 정확한 시점 타깃,5에폭 고정.
- exact_15: 같은 학습을15에폭까지 진행한 대조군.
- soft_mixed_15: 완만한 시점 타깃과 예측 시점 혼합,15에폭 고정.
- train_constant: 각 학습 분할의 시간 중앙값·다수 클래스만 사용하는 기준선.

두 학습 방식은 동일 초기화·동일 영상 순서를 사용한다. 장면 혼합 선택 RNG를 분리한다.
외부 평가 분할로 최적 에폭을 고르지 않는다. 기존 모델의 최적15에폭을 참고해 계획을
고정했으므로 과거 개발 표본 활용 영향을 완전히 제거한 새 테스트는 아니다.
한 seed의 탐색적 교차검증이며 최종 공식점수 개선을 보증하지 않는다.
영상별 평균과 출처별 동일 가중 평균, 출처별 지표·혼동행렬을 모두 남긴다.

## 기존 선택 모델의 오류 분석 완료

기존 검증15영상에서 저장 모델 재추론과 저장 예측 CSV가 정확히 일치했다.
충돌 ±0.3초66.7%, 진입40.0%, 회피 공간46.7%, 방향86.7%를 재현했다.
진입 MAE0.86초, 충돌 MAE0.613초다.
회피 공간 없음11건 중7건을 있음으로 오판했다(없음 재현율4/11).
출처0026은 충돌1/4정답, 충돌 MAE1.425초로 실패가 집중됐다.

진단 목적으로 scene head에 정답 충돌·진입 시점의 특징을 넣었을 때:
회피 공간46.7%로 동일, 방향86.7%→73.3%. 정답 시점 사용이 성능 상한은 아니며
학습·입력분포 차이가 있을 수 있다. 현재 자료에서는 회피 공간 부진을 시점 오차만으로
설명할 근거가 없다. 이 진단은 추론 시 정답 사용을 제안하거나 제출 코드를 바꾼 것이 아니다.
